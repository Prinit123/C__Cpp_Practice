## ▶️ How to Run the Programs

### 1. Clone the repository

```bash
git clone https://github.com/Prinit123/c-cpp-Practice.git
```

### 2. Open the project folder

```bash
cd c-cpp-Practice
```

### 3. Compile and run a C program

```bash
gcc c/lecture/01-introduction.c -o program.exe
./program.exe
```

### 4. Compile and run a C++ program

```bash
g++ "c++/class/1_class.cpp" -o program.exe
./program.exe
```

**Note:** These commands assume GCC/G++ is installed and available in your system PATH. On Windows PowerShell, you can run the compiled program using `.\program.exe`.
